# Stage A5 — portable certified evidence

Stage A5 separates ordinary development cache from certification evidence.

`agent check run` may use the disposable stage cache for fast local iteration. `agent check certify` never trusts that cache. It uses a separate content-addressed PASS evidence store and promotes newly executed PASS facts only after the complete certification profile succeeds.

## Configuration

```json
{
  "check": {
    "certification": {
      "profile": "full",
      "reusableSuites": ["tests", "compile"],
      "globalInputs": ["agent-tools.json", "agent-check.policy.json"],
      "evidencePath": ".agent-cache/check-certified-evidence-v1.json"
    }
  }
}
```

The certification profile must use `selection: all` and must select the complete `suiteOrder`. Reuse is opt-in per suite. Suites omitted from `reusableSuites` always execute physically.

Certified identity includes the resolved command, declared environment/cwd/result adapter/contracts, tool identity, declared suite inputs, certification global inputs and a fingerprint of the Agent DevTools Python engine itself. Therefore a verifier-engine change invalidates prior certified facts automatically.

## Cold and incremental certification

```bash
python agent.py check certify --cold
python agent.py check certify
```

`--cold` ignores all certified PASS evidence and physically executes every certification item. Ordinary certification may reuse only matching evidence promoted by an earlier completely successful certification.

If the evidence file is absent or corrupt, certification fails safe to physical execution. A successful run rebuilds the store. A failed/interrupted run never flushes queued evidence.

## File-set evidence

Reusable `fileSet` suites certify each matched file independently. A changed file executes again while unchanged matching files may reuse their own PASS evidence. Declared `inputs` remain shared dependencies of every file item; authors should therefore put only genuinely shared inputs there when they want granular reuse.

## Generated outputs

For a suite with `outputs.capture`, matching certified input identity is not enough: current generated bytes must still match the recorded SHA-256 hashes. Missing or tampered outputs force physical execution.

## Deliberate boundary

Stage A5 does not implement exact replay or release packaging. Those remain separate because certified semantic correctness and source/generated reproducibility are distinct proofs.
